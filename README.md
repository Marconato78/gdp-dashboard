# :earth_americas: Plantilla de panel de PIB

Una aplicación simple de Streamlit que muestra el PIB de diferentes países del mundo.

[![Abrir en Streamlit](https://static.streamlit.io/badges/streamlit_badge_black_white.svg)](https://gdp-dashboard-template.streamlit.app/)

### Cómo ejecutarlo en tu propia máquina

1. Instala los requisitos

   ```
   $ pip install -r requirements.txt
   ```

2. Ejecuta la aplicación

   ```
   $ streamlit run streamlit_app.py
   ```
